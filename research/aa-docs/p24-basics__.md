2026.10.1

1.0 更新日志

建议先重新手动安装。1.0 是一次大更新，为避免与旧版本冲突，正式使用 AA 之前，建议在打开 AA 时重新手动安装一次。

- 支持 AzureArchive 的 mod 制作

- 支持在 AA 内直接查询额外指令，并支持输入时自动补全（位于额外指令框左下角）

- 修正 [aa00cc] 这类颜色指定语句在换行场景下无法生效的问题

- 新增 Auto 选项功能：在选项编辑界面点选对应选项（非编辑文本）可设为 Auto 并设置点击时间，自动播放时会默认选择该选项

- 修正 png 转立绘功能中，混入不符合命名规则的文件导致 AA 崩溃的问题

- 新增加载自定义背景效果的功能

- 优化 Spine 模型的加载速度

- 新增 BGM 与音效的收藏功能

- 修复收藏取消后 None（无声）不会自动恢复置顶的问题

- 支持 MCP 服务，可由 AI 辅助使用 AA

- 新增立绘前后顺序优先显示，避免角色被其他角色的翅膀等部件遮挡

- 优化内存占用，运行更流畅

- 修复旧版本工程文件的兼容问题

- 修复鉴赏模式左下角弹出 HTTP/1.1 404 Not Found 的问题

- 修复主界面弹出 Failed to load BGM Theme_12: Dependency Exception 的问题

- 修复 MCP 服务中，AI 无法在脚本里选择和放置资源包中立绘资源的问题

导入 png

在之前导入骨骼的界面处，现在可以选择一个文件夹进行导入。

在这种模式下， AA 会扫描文件夹中名字包含 '00' ~ '12' 和 '99' 和 'halo_01' 'halo_02' 的 'png' 格式图片，将他们作为模型资源中对应表情下显示的内容。
